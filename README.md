# 3D 晶体结构与晶格缺陷分析工具

React + Vite + TypeScript + React Three Fiber 的材料科学可视化基础项目，用于展示面心立方晶格、空位缺陷、替位缺陷与刃型位错。

## 当前能力

- 三维晶格原子与最近邻连接
- 空位、替位和刃型位错模型切换
- 晶胞数量调整
- 晶面透明度调整
- 缺陷指标展示
- 三维旋转、缩放和结构观察
- 结构快照操作入口
- 本地 CIF 文件导入：文件选择、解析校验、坐标归一化与三维场景接入

## CIF 导入

- 文件仅在浏览器本地解析（`File.text()`），不会上传。
- 支持 `_atom_site_fract_*` 分数坐标与 `_atom_site_Cartn_*` 直角坐标；坐标经回卷、分数→直角转换、居中与等比缩放归一化后接入三维场景。
- 导入策略为**整批提交**：解析、必填字段校验（晶胞棱长、原子坐标列）与坐标合法性校验全部通过后，才一次性替换当前结构并更新模型、原子数与晶格参数摘要；任一环节失败（解析失败 / 字段缺失 / 坐标非法）都会保留原模型并给出分类提示。
- 导入后最近邻连接线、晶面透明度与内置缺陷切换（空位 / 替位 / 刃型位错）对新结构仍然可用。
- `public/samples/` 提供测试样品：`al-fcc.cif`、`nacl.cif`、`si-diamond.cif` 为合法结构，`broken-missing-cell.cif`（字段缺失）与 `broken-bad-coords.cif`（坐标非法）用于验证失败路径。

## 启动

```bash
npm install
npm run dev
```

后续可接入晶面选择、晶格常数计算、位错密度分析、XRD 辅助数据和真实分子动力学结果。
